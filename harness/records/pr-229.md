# PR #229 cargo-mutants を CI に入れ、PR の差分で生き残った変異を落とす

- マージ日: 2026-11-21
- 関連 Issue: #221
- 差分規模: 10 ファイル / +397 -3

## ゴールと結果

PR で変えた行に、テストで落ちない変異（生き残り）が残ったら CI を落とす（利用者の希望「ミューテーションテスト」）。達成。`.github/workflows/mutants.yml` がマージコミットの `HEAD^1..HEAD` の差分を `cargo mutants --in-diff` に渡し、`mutants.out/missed.txt` が空でなければ落とす。`cargo install` は `global-min-publish-age` を見ないので、入れる前に `harness/deps/tool-cooldown.sh` で公開からの期間を確かめる。テストの無い関数を足した一時コミットで、ジョブが赤になり注釈とアーティファクトが出ることを本物の CI で確かめた。
