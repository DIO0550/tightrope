# PR #238 test-reviewer が手で壊す前に、差分の行の変異（cargo-mutants）の生き残りを読む

- マージ日: 2026-11-21
- 関連 Issue: #222
- 差分規模: 4 ファイル / +96 -19

## ゴールと結果

test-reviewer は、手で壊す前に `cargo mutants --in-diff` で差分の行の変異を走らせ、生き残り（`missed.txt` の 1 行）を指摘として返す。cargo-mutants が作った変異は手で重ねず、手で壊すのは `mutants.json` に無い形だけにする（利用者の希望「ミューテーションテスト」）。達成した。

- 報告は「走らせた / 対象外 / 走らせられなかった」の 3 通りの表で書く。
- `harness/mutants/README.md` の「走らせる」ブロックは、次のときに止まる。
  - 基点が取れない
  - 追跡していないファイルの差分を作れない
  - 一時ディレクトリを作れない
- 追跡していないファイルの名前をオプションとして読まない。
- 文書とコメントだけの差分なので Red は無し。
