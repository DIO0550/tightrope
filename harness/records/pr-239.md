# PR #239 PR の Red のコミットで検査が落ち、先端で通ることを CI が確かめる

- マージ日: 2026-11-21
- 関連 Issue: #224
- 差分規模: 10 ファイル / +661 -6

## ゴールと結果

PR の Red のコミット(トレーラ `TDD: red`)で pre-push が落ち、PR の先端で通ることを CI(`TDD Red` ワークフロー)が確かめる。Red が 2 つ以上の PR も落とす(利用者の希望「必ず t-wada TDD のレッドから確認する」)。達成した。

- Red が無い PR を落とすのは #234、Red で落ちたものを名前ごとに先端で照らすのは #235 に分けた。
- この PR 自身の Red(08aa548)で CI が「通過(Red で落ち、PR の先端で通った)」になった。
- 必須チェックへの登録は利用者に頼んだ(リポジトリの設定なので、この PR の差分ではない)。
