# PR #245 PR に入った Cargo.lock の版を、足したコミットの時点の公開からの期間で確かめる

- マージ日: 2026-11-21
- 関連 Issue: #244
- 差分規模: 16 ファイル / +1104 -178

## ゴールと結果

PR に入った Cargo.lock の変更について、その版を足したコミットの時点で crates.io への公開から 14 日経っていない版があれば、PR の CI が落ちる。達成した。

- 計画の検証を受けて、ゴールを「push の後で必ず」から「PR に入った lock の変更」に絞った。限界(main への直接 push、期間後の rebase、PR 自身の設定・スクリプトで判定すること)は README に書いた。
- #211 / #210 の merge ref に本物の index で当て、15 件 / 21 件を確かめて exit 0。
- `[["package"]]` とインラインの `package = [...]` で数え漏らす穴は #246 に分けた。
- 必須チェックへの登録は利用者に頼んだ(リポジトリの設定なので、この PR の差分ではない)。
