# PR #248 cargo の検査を --locked で走らせ、Cargo.lock の外から依存を解決しない

- マージ日: 2026-11-21
- 関連 Issue: #243
- 差分規模: 18 ファイル / +412 -59

## ゴールと結果

ゴール: push 前の検査（pre-push）・CI の check ジョブ・編集後のフック・cargo-mutants の cargo が、Cargo.lock の外から依存を解決しない（lock に無い依存があれば lock を書き換えずに止まる）。

達成。cargo の引数を `harness/githooks/lib/rust-checks.sh` に寄せ、pre-commit・pre-push・CI の check ジョブ・編集後のフックがそこを通る。cargo-mutants は `.cargo/mutants.toml` で `--locked` を渡す。決めた入口の外（`.claude/settings.json` の許可パターン・rust-analyzer）は #249 に回した。
