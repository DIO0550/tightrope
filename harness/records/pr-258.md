# PR #258 src/ を crates/ の Cargo workspace に移す

- マージ日: 2026-11-22
- 関連 Issue: #253
- 差分規模: 60 ファイル / +168 -69

## ゴールと結果

ゴール: `src/` を `crates/` の Cargo workspace(domain / presentation / infrastructure / tightrope)へ移し、テストの名前と本数(26 本)を変えずに、build・clippy・test・pre-push・CI が通る状態にする。

達成。移す前と同じ名前の 26 本が走り、pre-push は 34 件通過、CI は mutants を含む全ジョブが通った。自動のテストで守れていない穴 2 つ(crate の lints の継承漏れ・pre-push が検査に渡す根)は #254 と #259 へ回した。
