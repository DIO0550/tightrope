# PR #271 crate 間の依存を許可表と突き合わせて落とす

- マージ日: 2026-11-27
- 関連 Issue: #254
- 差分規模: 9 ファイル / +607 -7

## ゴールと結果

ゴール: workspace の crate のどれかに、#254 の許可表に無い依存（workspace の crate・外部 crate のどちらも）を足すと、pre-push と CI がどの crate のどの依存かを出して落ちる。

達成。`harness/githooks/lib/crate-deps.sh` が `cargo metadata --no-deps` を jq で読み、スクリプト内の許可表と照らす。判定表は 28 ケース。許可表どおりにするため、利用者の選択で引数の解釈を presentation の `Cli::from_process_args` に寄せ、tightrope(bin) から clap を外した。申し送りのうち `resolve.sh add` の件は #269、lints 継承の検査は #270 に分けた。presentation がプロセスを終える形の見直しは #252 に申し送った。
