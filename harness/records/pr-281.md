# PR #281 workspace の lints の継承を落とす検査を足す

- マージ日: 2026-11-27
- 関連 Issue: #270
- 差分規模: 10 ファイル / +444 -53

## ゴールと結果

workspace の各 crate が根の `[workspace.lints]` を `[lints] workspace = true` で受けていることを検査で落とせるようにする(抜けた crate の名前を出して落ちる)。あわせて 4 crate の本番コードの `unwrap()` / `expect()` が clippy で落ちることを判定表で確かめる。達成した。Red 6a21bed で判定表 25 件すべて broken、先端で 30 件 ok。domain の `[lints]` を一時的に消すと pre-push が 失敗 2 / 通過 40 で落ちることを実物で確かめた。
