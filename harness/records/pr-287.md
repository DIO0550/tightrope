## ゴールと結果

I/O を持たない crate(domain / presentation)で、標準入出力・環境変数・ネットワークを使うコードを書くと `cargo clippy` が落ち、その一覧の欠け・余分・綴りの誤りを判定表が落とす。達成した。domain / presentation の clippy.toml に disallowed-macros を新設して 50 項目を足し(計 95 件)、判定表は Red 0752983 で NG 102 / ok 123、先端で 225 件 ok。presentation の clap の経路(`from_process_args`)は依存先の中なので通り、終了コードの扱いは #252 の申し送りへ送った。std に今後足される env / net の項目は #274 へ申し送った。
