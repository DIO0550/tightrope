## ゴールと結果

`harness/githooks/lib/` の test-placement.sh / test-file-length.sh / comment-style.sh が、根を渡されないときに単一 crate の頃の根(`src` / `tests`)へ黙って倒れず、何を渡すかを言って exit 2 で落ちる。深い階層のファイルも検査の対象であることを判定表が守る。達成した。test-placement / test-file-length は根がちょうど 1 つで空でないときだけ走り(受け取りは新しい `crate-src-root.sh` の `crate_src_root_of`)、comment-style は根が 0 個なら exit 2。判定表は Red 24039a4 で NG 7 件、先端で 3 本とも全件 ok(24 / 23 / 16)。既存の「検査できない」ケースの照らし方は #290、`return 2` / `|| exit 2` を外す変異の生き残りは #280、comment-style-cases.sh の失敗する awk の手書きは #289 へ分けた。
