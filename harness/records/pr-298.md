## ゴールと結果

例の `resolve.sh add …` が根で `could not determine which package to modify` で落ちていたのを、外部依存を足す手順を 1 つに決めて例を揃える。達成した。手順は「`resolve.sh add <crate> -p <メンバー> --dry-run` で版を見る → 根の `[workspace.dependencies]` に 1 行手で書く → `resolve.sh add <crate> -p <メンバー>`」で、`harness/deps/README.md` に節「依存を足す」を置き、AGENTS.md(1 行を 1 行、645 / 645 のまま)・`resolve.sh` の使い方・根 `Cargo.toml` のコメントを揃えた。写しで anyhow(最新 1.0.105 は期間内)を足し、根に `1.0.104`、メンバーに `.workspace = true` が入ることを確かめた。Issue 備考の「`.workspace = true` で受ける」の検査は、`cargo metadata` が継承と直接書きを見分けないので #254 と同じ読み取りでは済まず、足さないと決めた(記録に 0 件)。Red: 無し(文書だけ)。
