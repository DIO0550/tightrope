# PR #301 clippy を rustflags の入口から切り離し、設定の rustflags を渡しうる箇所を落とす

- マージ日: 2026-11-28
- 関連 Issue: #279
- 差分規模: 10 ファイル / +527 -11

## ゴールと結果

rustflags(環境変数・`.cargo/config.toml` の `[build]` / `[target.*]`)の `-A` / `-W` / `--cap-lints` で、manifest を変えずに workspace の lints の deny が外れる経路を、pre-push と CI で落とす(または効かなくする)。環境変数の扱いを決めて Issue に書く。達成した。`rust-checks.sh` の clippy を `CARGO_ENCODED_RUSTFLAGS=` で走らせて stable の rustflags の入口をすべて塞ぎ(環境変数は「見つけたら落とす」ではなく「空にする」に決めた)、素の `cargo clippy` で効く設定ファイルの rustflags は `cargo-config-rustflags.sh` が場所を出して落とす。判定表は Red 0a7364a で pre-push の失敗 3 / 通過 42、先端 8d62845 で 46 件通過。rustflags 以外で deny が外れる経路(`[env] CLIPPY_ARGS`・rustc-wrapper・`[alias]`・`CARGO_ENCODED_RUSTDOCFLAGS` など)は #295 に分けた。
